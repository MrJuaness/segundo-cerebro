Linux es el sistema operativo más utilizado en los servidores con un 96,3% de participación de mercado. La mayoría de las herramientas de hacking son construidas para Linux, y si estás aprendiendo a programar, en algún momento vas a tener que aprender Linux, ya que lo más probable es que tus aplicaciones las termines montando en un servidor Linux

linux un SO al igual que Windows, MAC OS, Android, IOS. Los sistemas operativos se componen de dos partes:
1. Las aplicaciones: Como el explorador de archivos, un explorador web, una terminal o un editor de texto.
2.  El kernel: Se encarga de comunicarse con el hardware (la parte física del computador, como la memoria RAM, la CPU, la tarjeta gráfica, etc.).
opularmente se le llama "Linux" al sistema operativo completo. Sin embargo, Linux es estrictamente el nombre del kernel

Historia y origen:
- En el comienzo, **Richard Stallman** quería construir herramientas que fuesen de código libre construyó muchas aplicaciones dentro de esta capa en un proyecto llamado GNU
- Para crear un sistema operativo completo necesitaba un kernel, y ahí fue cuando conoció a **Linus Torvalds**, quien estaba creando un kernel de código abierto. Se juntaron y crearon el proyecto GNU/Linux
Distribuciones ("Sabores" de Linux): son sistemas operativos creados al combinar un conjunto de aplicaciones con el kernel de Linux
