# Implantación de Aplicaciones Web — Unidad 1
## Test de repaso: preguntas y respuestas correctas

Tema: Conceptos generales de la arquitectura de aplicaciones web 
### 1. ¿Cuáles son las dos partes principales en las que se compone una aplicación web?
- Base de datos y servidor web.
- ✅ **Lado del cliente (front-end) y lado del servidor (back-end).**
- Interfaz de usuario y lógica de negocio.
### 2. ¿Cuál de las siguientes afirmaciones describe una característica propia de las aplicaciones web frente a las de escritorio?
- Son más rápidas y eficientes en el uso de recursos del sistema.
- Ofrecen mayor nivel de personalización y funcionalidad específica.
- ✅ **Son accesibles a través de un navegador y no requieren instalación, lo que facilita su uso en múltiples dispositivos.**
### 3. ¿Qué papel desempeña el servidor en la arquitectura cliente-servidor?

- Es el dispositivo o programa que realiza peticiones de servicios o recursos.
- ✅ **Es el programa o dispositivo encargado de proveer los recursos o servicios requeridos por el cliente.**
- Gestiona únicamente la interfaz gráfica de usuario.
### 4. ¿Cuál de las siguientes es una ventaja de la arquitectura de tres niveles frente a un diseño menos modular?

- Elimina la dependencia de una conexión de red constante.
- Evita la sobrecarga del servidor al reducir el número de solicitudes.
- ✅ **Permite modificar o ampliar cada capa de manera independiente, facilitando la adaptación del sistema a las necesidades cambiantes del negocio.**
### 5. ¿Qué protocolo añade cifrado mediante SSL/TLS a la transferencia de datos y resulta imprescindible en transacciones como compras o banca electrónica?
- HTTP
- FTP
- ✅ **HTTPS**
### 6. En el patrón Modelo Vista Controlador (MVC), ¿qué componente se encarga de manejar la lógica y las operaciones de la aplicación?
- El modelo, que alberga los datos.
- La vista, que corresponde a la interfaz de usuario.
- ✅ **El controlador, que maneja toda la lógica y las operaciones.**
### 7. ¿Qué práctica de arquitectura web consiste en diseñar aplicaciones que funcionen correctamente en distintos dispositivos y tamaños de pantalla?
- La minificación de CSS y JavaScript para reducir el tiempo de carga.
- La autenticación de usuarios y la encriptación de datos para proteger la aplicación.
- ✅ **El responsive design, que garantiza una experiencia funcional y visual adecuada en cualquier dispositivo.**
### 8. ¿Qué caracteriza al modelo arquitectónico de microservicios frente al enfoque monolítico?
- Toda la aplicación se desarrolla como una única unidad indivisible para facilitar su despliegue.
- Integra servicios distribuidos e independientes mediante un bus de servicios compartido.
- ✅ **La aplicación se descompone en servicios independientes, cada uno operando en su propio proceso, lo que mejora la escalabilidad y el mantenimiento.**
### 9. ¿Cuál es la función principal de la capa de lógica de negocio en la arquitectura de tres niveles?

- Proporcionar una interfaz de usuario intuitiva y eficiente.
- ✅ **Procesar los datos y ejecutar las reglas y procesos de negocio.**
- Gestionar el almacenamiento, la recuperación y la manipulación de los datos.
### 10. ¿Cuál de los siguientes representa un desafío propio de la arquitectura cliente-servidor derivado de la centralización de datos en el servidor?
- La necesidad de instalar el software en cada dispositivo cliente.
- La dificultad para actualizar la lógica de negocio sin detener el sistema.
- ✅ **Un ataque al servidor puede comprometer la seguridad de todos los datos centralizados.**
